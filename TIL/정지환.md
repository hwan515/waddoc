# 기획서
1) 오늘 확정한 한 줄 요약

메디로버 홈케어
도서/산간 지역의 고령·만성질환 환자를 위해, 로봇이 집 앞까지 방문해서
본인 확인 → 동의 → 생체 측정 → 보호자 동행 3자 화상진료 → 방문 이력/다음 예약까지 제공하는 방문형 비대면진료 플랫폼.

2) 문제를 “섬닥터/마을회관 모델의 3가지 한계”로 고정했습니다

결국 이동해야 함
마을회관형은 완전 무이동이 아니고, 고령자/거동불편/악천후에서 장벽이 큼.

공용 공간이라 프라이버시 설계 부담이 큼
병명/처방/진료 대화가 노출될 가능성이 생기면, 제도적으로 “불법 단정”까지는 아니어도 설계 리스크가 커짐.

디지털 조작이 여전히 어려움
앱 설치/회원가입/인증/검색이 고령층 진입장벽.

3) 차별점은 “로봇이 간다”가 아니라, 4개로 정리했습니다
A. 방문형 진료 접점

환자가 이동하지 않음

마을회관은 진료 장소가 아니라 충전/보관 거점

B. 프라이버시 모드 (이게 핵심)

집 앞 방문만으로 해결되는 게 아니라, 설계를 넣어야 함

외부 화면: 병명/처방약명 비노출

오디오: 외부 스피커 금지, 수화기/이어셋 모드

상세정보: 의사 대시보드에만 표시

보호자: 위임 범위에 따라 정보 차등

세션 종료: 로컬 캐시 즉시 삭제 + 초기화

C. 무앱 / 저조작 UX

환자 앱 없음

환자 조작은 “진료 시작 버튼 + 수화기” 중심

보호자/운영자가 대부분 입력 대행

D. 만성질환 루틴 (MVP 질환 고정)

고혈압 재진 관리로 고정

반복성이 높고, 측정이 단순하고, 운영 리스크가 낮음(혈당 채혈보다 안전)
