유니티 - ros2간 데이터 전송
단일환경 vs 개별 환경

- 단일환경 데이터 스트림 이득
- 개별환경 cpu 및 gpu 자원 이득

-> 단일환경 zero-copy 불가능, 유니티 - ros2간 분리된 실행환경
-> 개별환경 유니티-ros간 데이터는 직렬/tcp = 네트워크에 엄청난 부하
결국 단일환경이 유리함
-> C#의 통신 노드를 C++로 ros환경에 맞게 직접 세팅하는게 제일 효율적인 방법
- 일단은 기본 환경에서 tcp,직렬데이터의 레이턴시 확인 후(테스트)후 진행해야함.

그 외 현재 진행중인 로컬pc에  인코딩 가속 하드웨어가 존재하여 - 스티리밍(rtsp)에 부하는 없음<- 파이프라인 구축 필요
```
RUN apt-get update && apt-  install -y \
    libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev \
    gstreamer1.0-plugins-good gstreamer1.0-plugins-bad \
    gstreamer1.0-plugins-ugly gstreamer1.0-rtsp \
    && rm -rf /var/lib/apt/lists/*
```
