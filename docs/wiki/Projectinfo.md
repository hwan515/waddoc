# 프로젝트 소개

도서·산간 의료취약지 고령층을 대상으로, 환자가 앱/스마트폰 없이 전화(IVR+TTS) 로 진료를 예약하고, 예약 시간에 맞춰 자율주행 차량(로봇)이 집 앞까지 이동해 본인확인/동의 → 기초 생체정보 측정(더미 가능) → WebRTC 화상진료 연결 → 관제/복구까지 end-to-end 시나리오를 재현하는 “방문형 비대면 진료” MVP이다.
핵심 성과 기준은 AI 모델 성능이 아니라 주행 안정성, 본인확인/동의의 무결성, 화상 연결 안정성, 관제 기반 예외 대응 및 복구를 실제 운영 관점으로 끊김 없이 이어붙이는 것이다. (완성 목표: 2026-03-30)
