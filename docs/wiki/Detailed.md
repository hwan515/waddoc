# 세부 기능 리스트

## 1) 환자(고령층) 채널: 전화(IVR/TTS) 중심

* **전화 예약**

  * “진료 예약 / 예약 확인·취소 / 다시 듣기(0번)” 메뉴
  * 날짜·시간 선택(가용 슬롯 안내), 주소(또는 사전 등록 주소) 확인
  * 콜백 번호 확인, 예약 완료 안내(TTS)
* **예약 확인/변경/취소**

  * 본인 식별(전화번호 + 생년월일/간단 PIN)
  * 예약 상세(일시/예상 도착/담당 의료진) 음성 안내
  * 취소 시 취소 사유 선택(옵션)
* **진료 전 안내**

  * 로봇 도착 전 자동 안내 전화(“몇 분 후 도착, 현관 앞 대기”)
  * 준비물 안내(신분증/복용 중 약 봉투 등)

## 2) 보호자 채널: 최소 UI + 상태 확인(권장)

> “환자·보호자는 음성만”을 넘어서, **약/상태/내역 확인 화면**이 필요하다고 했으니 최소 기능으로 잡는다.

* **환자 상태/일정 조회**

  * 예약 일정, 로봇 이동 상태(출발/이동 중/도착/진료 중/복귀)
  * 예외 발생 알림(지연/경로 이탈/통신 불안정/진료 실패)
* **진료 요약/처방 확인**

  * 진료 종료 후 요약(간단 소견/주의사항)
  * 처방전/복약 안내(텍스트+PDF 링크 형태 가능)
* **동의 관리(대리 동의 포함)**

  * 환자 대리 동의 설정(관계/서명/인증)
  * 동의 이력 조회(시간, 항목, 버전)

## 3) 운영자(관제/운영) 콘솔

* **예약/배차 운영**

  * 예약 목록/캘린더 뷰, 지역/우선순위/차량별 필터
  * 차량(로봇) 배정, 출발 지시, 일정 재조정
* **실시간 관제**

  * 지도 기반 위치/경로/속도/정지 상태
  * 통신 상태(신호/지연/패킷 드롭 지표), 배터리/센서 헬스
  * 현장 도착 확인(지오펜스 진입, 도착 버튼/자동 판정)
* **예외 대응/복구 시나리오**

  * 원격 정지(E-stop), 안전 모드 전환
  * 경로 재계획(리루팅) / 원격 텔레옵(가능하면) / 회수 요청
  * 현장 실패 시 “진료 전환 정책”: 전화 진료로 전환/재방문 예약
* **민원/운영 로그**

  * 통화 로그(IVR 단계별), 이동 로그, 진료 로그, 장애 티켓화
  * SLA 리포트(성공률/지연률/중단률)

## 4) 의료진(원격 진료) 웹

* **세션 준비**

  * 예약 기반 대기실(환자 정보, 사전 문진/기본 정보)
  * 로봇 도착/본인확인 완료 시 “진료 시작” 활성화
* **WebRTC 진료**

  * 영상/음성 통화, 네트워크 품질 표시(기본)
  * 진료 중 메모/소견 입력
* **처방/기록**

  * 처방 생성(약/용량/기간), 진료 기록 저장
  * 환자/보호자에게 요약 자동 발송(문자/앱 알림/카톡 등은 MVP 범위에 맞게 선택)

## 5) 로봇/차량(현장 장치) 기능

* **주행/도착**

  * 미션 수신 → 경로 주행 → 지오펜스 진입/도착 판정 → 안전 정차
  * 장애물/안전 규칙(최저 수준): 위험 시 정지/관제 호출
* **본인확인**

  * PIN/QR/신분증 확인 중 1~2개 선택(MVP는 단순 PIN도 가능)
  * 실패 시 재시도 → 원격 지원 요청
* **동의 획득**

  * 화면/음성으로 동의 항목 안내 → 버튼/서명/확인 입력
  * 동의 버전/타임스탬프 저장
* **Vital 측정(더미 가능)**

  * 혈압/체온/산소포화도 중 선택(실기기 연동 or 더미 입력)
  * 측정 실패 처리(재측정/수동 입력/스킵 사유 기록)
* **진료 연결**

  * WebRTC 세션 자동 접속, 품질 저하 시 재연결/대체 플로우(음성/전화)
* **미션 종료/복귀**

  * 진료 종료 확인 → 복귀 미션 수행 → 충전/대기 상태 전환

## 6) 공통(백엔드/플랫폼) 기능

* **계정/역할**

  * 운영자/의료진/보호자 권한 분리(RBAC)
* **미션/상태 머신**

  * 예약→배차→이동→도착→본인확인→동의→vital→진료→종료→복귀
  * 각 단계별 타임아웃/재시도/실패 전이 기록
* **알림/통지**

  * SMS/전화(TTS)/푸시 중 MVP 채널 선택
  * 지연/실패/완료 이벤트 기반 알림
* **감사 로그/데이터 보관**

  * 동의/본인확인/진료 이벤트 로그(위변조 방지 최소 조치)
  * 개인정보 마스킹/접근 로그(최소)
